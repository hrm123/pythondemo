Note - conda install inherently manages the installation order by first resolving all dependencies using its satisfiability solver, then installing packages from the highest priority channel, ensuring correct versions and avoiding conflicts, which is crucial for creating working environments. It installs binary packages and their specific dependency versions into isolated environments, preventing clashes, and prioritizes packages in your configured channel order. Somehow I felt better to explicitly specify the version numbers in the conda install. Example - for native windows gpu tensorflow=2.10.0 is the last version which supports.
